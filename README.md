# Fabric Check 💸

Stop paying for the label. Check the fabric.

A small, free, no-backend web app: enter a garment's price and fabric composition (or scan its care tag), and get a plain-English verdict on whether the price matches the fabric quality.

## Running it locally

Just open `index.html` in your browser. No install, no build step, no server needed.

## Tech

Plain HTML, CSS and JavaScript only. No frameworks, no backend, no API keys. Deployed on GitHub Pages.
